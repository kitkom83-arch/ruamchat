# คู่มือผู้ใช้ ruamchat (ภาษาไทย)

คู่มือนี้อธิบายฟีเจอร์ใหม่ 2 ส่วนแบบเข้าใจง่าย สำหรับผู้ใช้ทั่วไป (ไม่ต้องมีพื้นฐานเทคนิค):

1. **ตัวสร้างแชทบอทแบบลากวาง (Flow Builder)** — ที่หน้า `/flows`
2. **การส่ง/รับ รูปและไฟล์ (Media)** — ที่หน้าแชท `/` และหน้าเดโม `/webchat-demo`

> ⚠️ หมายเหตุความปลอดภัย: ระบบยัง "ล็อกการส่งออกจริง" ไปยังแพลตฟอร์มภายนอกไว้ (LINE/Telegram/Messenger/Instagram) จนกว่าผู้ดูแลจะเปิด allowlist ให้ — ดูหัวข้อ "สิ่งที่ต้องเตรียมก่อนใช้งานจริง" ท้ายคู่มือ

---

## 1) เมนูซ้าย + การพับเก็บแผง (ทุกหน้า)

- แถบเมนูซ้ายจะแสดงอยู่ทุกหน้า: Inbox, Analytics, Contacts, Broadcasts, AI Center, Flows, Webchat Demo, Settings
- กด **ปุ่มพับ (‹ ›)** เพื่อย่อเมนูให้เหลือแค่ไอคอน หรือกางออกเพื่อเห็นชื่อเมนู — ระบบจะจำสถานะไว้ให้อัตโนมัติ
- ในหน้าแชท คอลัมน์ **รายการห้องแชท (ซ้าย)** และ **ข้อมูลลูกค้า (ขวา)** พับเก็บได้ เพื่อให้ช่องแชทตรงกลางกว้างขึ้น

---

## 2) ตัวสร้างแชทบอทแบบลากวาง (หน้า Flows)

### เริ่มต้น
1. เข้าเมนู **Flows**
2. ลาก "การ์ด" (node) จาก **แถบซ้าย (Palette)** มาวางบนพื้นที่ทำงาน (Canvas)
3. ลากเชื่อมจากจุด **Continue** ของการ์ดหนึ่งไปยังอีกการ์ด เพื่อกำหนดลำดับการทำงาน

### ชนิดการ์ดที่ใช้บ่อย
- **Send Message** — ส่งข้อความ/ข้อความริช (ปุ่ม, การ์ด, quick reply)
- **AI Reply** — ให้ AI ตอบ
- **Condition** — แยกเส้นทางตามเงื่อนไข
- **Delay** — หน่วงเวลา
- **Action** — ติดแท็ก/เปลี่ยนสถานะ/มอบหมายแอดมิน ฯลฯ
- **End** — จบ flow

### แก้ข้อความบนการ์ดได้ทันที
- การ์ด Send Message / AI Reply มีช่อง **"Type a message…"** พิมพ์แก้ได้บนการ์ดเลย ไม่ต้องเปิดแผงขวา
- กดปุ่ม **+ Add Content** บนการ์ด เพื่อเพิ่ม: ข้อความ / รูป / วิดีโอ / GIF / ไฟล์ / ตำแหน่ง / ปุ่ม / Quick reply

### เพิ่มการ์ดถัดไปจากปุ่ม "+"
- คลิกจุด **Continue** ท้ายการ์ด → เลือกชนิดการ์ดจากเมนูที่เด้งขึ้นมา → ระบบสร้างการ์ดใหม่และเชื่อมเส้นให้อัตโนมัติ

### เครื่องมือเมื่อชี้ที่การ์ด (hover)
- 👁️ ดูตัวอย่าง · ▶️ ทดสอบ · 📄 ทำสำเนา (duplicate) · ✎ เปลี่ยนชื่อ · 🗑️ ลบ

### ข้อความริชตามแพลตฟอร์ม (แผงขวา)
เลือกแพลตฟอร์มแล้วตั้งค่าได้ พร้อมดูตัวอย่าง:
- **LINE:** Quick Reply, Flex/Carousel, ปุ่ม template
- **Telegram:** Inline Keyboard, Reply Keyboard, Commands
- **Messenger:** Generic Template (การ์ดสูงสุด 10), Quick Replies
- **Instagram:** Ice Breakers (สูงสุด 4), Quick Replies
- **Webchat:** Quick-reply chips

### บันทึก/เผยแพร่
- **Save / Save & close** — บันทึก flow
- **Publish** — ทำเครื่องหมายว่าเผยแพร่ (ยังไม่ยิงออกภายนอก)
- เมนู **"…"** — Rename / Duplicate / Flow Versions (ย้อนเวอร์ชันได้) / Delete
- **แถบล่างกลางจอ** — ดูตัวอย่าง, ซูมเข้า/ออก, Generate ด้วย AI, เพิ่มการ์ด

---

## 3) การส่ง/รับ รูปและไฟล์ (Media)

### ส่งไฟล์/รูปในหน้าแชท (`/`)
1. ที่ช่องพิมพ์ข้อความ กด **ไอคอนคลิปหนีบกระดาษ (📎)**
2. เลือกรูปหรือไฟล์ (จะเห็น **ตัวอย่างก่อนส่ง** เป็นชิปเล็ก ๆ กดกากบาทเพื่อลบออกได้)
3. กด **Send** — ส่งได้ทั้งข้อความพร้อมไฟล์ หรือส่งไฟล์อย่างเดียว

**ข้อจำกัดขนาดไฟล์:** รูปไม่เกิน **10 MB**, ไฟล์อื่นไม่เกิน **25 MB** (เกินขนาดระบบจะแจ้งเตือนและไม่ส่ง)

### การแสดงผลที่ได้รับ
- **รูป** แสดงเป็นภาพย่อ (คลิกเพื่อดูเต็ม)
- **ไฟล์** แสดงเป็นชิป (ชื่อ + ขนาด) คลิกเพื่อดาวน์โหลด
- **เสียง** เล่นได้ในแชท

### หน้าเดโม Webchat (`/webchat-demo`)
- แนบรูป/ไฟล์แล้วส่งในบทสนทนาเดโมได้เช่นกัน และแสดงรูปในกล่องสนทนา

---

## สิ่งที่ต้องเตรียมก่อนใช้งานจริง (Deploy)

ฟีเจอร์ media ทำงานครบใน dev แล้ว แต่ก่อน "ส่งออกจริง" ไปยังแพลตฟอร์มภายนอก ผู้ดูแลระบบต้องเตรียม:

1. **ที่เก็บไฟล์ระดับ production** — ตั้งค่า `MEDIA_STORAGE=s3` พร้อม bucket/สิทธิ์ หรือใช้ดิสก์ถาวร และตั้ง `MEDIA_PUBLIC_BASE_URL` ให้เป็น URL สาธารณะที่เปิดไฟล์ได้
2. **สิทธิ์/โทเคน media** ของแต่ละแพลตฟอร์ม (LINE / Telegram / Meta) สำหรับดึงและส่งไฟล์
3. **เปิด allowlist การส่งออก** — ตราบใดที่ยังไม่เปิด ระบบจะบล็อกการส่ง media ไว้เพื่อความปลอดภัย (สถานะ `provider_outbound_disabled` / `recipient_not_allowlisted`)

รายละเอียดค่าคอนฟิกทั้งหมดดูที่ [`docs/STEP6_MEDIA_DEPLOY_CHECKLIST.md`](./STEP6_MEDIA_DEPLOY_CHECKLIST.md)

> ห้ามใส่รหัสลับ/โทเคนจริงลงในโค้ดหรือไฟล์ที่ commit — ตั้งค่าผ่าน environment variables บนเครื่อง production เท่านั้น
